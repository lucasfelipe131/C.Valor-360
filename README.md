# Protótipo C.Valor 360

Protótipo estático e responsivo da Sprint 1.

## Como abrir

Abra o arquivo `index.html` em qualquer navegador moderno.

## Fluxo recomendado para demonstração

1. Abra “Visão do dia”.
2. Clique em João da Silva.
3. Clique em “Preparar visita com a VAL”.
4. Abra a VAL no canto superior direito.
5. Pergunte: “Como abordar o João?”

## Observação

Este protótipo não possui backend, autenticação real ou persistência. Ele serve para validar interface, fluxo e narrativa da apresentação.
